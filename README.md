# 光隙 · Luma

一个以照片为主角的原生 Mac 看图 App。暖黑背景、米白展签、完整画幅，给摄影作品留出安静的空间。

## 打开

双击同级目录中的 **Luma.app**。本次编译的版本适用于 **Apple Silicon Mac，macOS 14 或更新版本**。这是可本地运行的 0.2 原型，采用本地签名，尚未做 Developer ID 公证或 App Store 发布。

## 已实现

- 通过文件选择器一次导入多张照片，或拖放照片／文件夹到窗口；文件夹会递归导入子文件夹中的照片，跳过隐藏文件和非照片文件。
- 导入只保存原文件路径和 macOS 文件书签；不复制、移动、改写原片。
- 退出后恢复照片列表；重复导入同一路径会去重。
- RAW 通过 Core Image 解码；解码失败时尝试 Image I/O 预览，并明确显示“内嵌预览”。完全无法读取时显示错误。
- JPEG、PNG、HEIC、TIFF，以及系统 Image I/O 可以读取的其他静态照片格式。
- 左下角显示相机、镜头、焦距、光圈、快门、ISO 和拍摄日期，有“展签”和“极简”两种样式。
- EXIF 不存在时不编造参数；自动应用照片方向。
- 底部缩略图保留照片原比例：竖片用竖框、横片用横框，选中边框贴合照片。
- “照片／文件夹”两种浏览模式；文件夹可展开、收起，按实际层级显示目录名，方向键在当前展开的文件夹内切换。
- 已关联的文件夹在启动或 App 再次激活时自动重新读取，也可手动刷新，新增和移出的照片会同步到列表。目录暂时不可读时保留原有列表。
- 上一张／下一张、全屏、原生触控板缩放与滚动。
- 原图不可访问时可以重试、重新定位；右键菜单支持在 Finder 显示和从列表移除。移除只更新列表。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 导入照片 | ⌘O |
| 打开文件夹 | ⌘⇧O |
| 重新读取已关联的文件夹 | ⌘R |
| 上一张／下一张 | ← / → |
| 显示或隐藏拍摄参数 | I |
| 显示或隐藏缩略图 | T |
| 适应窗口 | ⌘0 |
| 放大／缩小 | ⌘+ / ⌘− |
| 从列表移除 | Delete |

触控板双指捏合缩放，放大后双指滚动查看不同区域。缩放倍率相对于“适应窗口”，不是传感器像素的 1:1 倍率。

## 文件夹模式

点击底部“打开文件夹”选择原始照片目录。底部显示目录及子目录，例如 `sony`、`sony / 8.18`；数字表示每个目录直接包含的照片数量，子目录单独显示。点击目录展开它的照片，再次点击收起；每次展开一个目录。

单独导入的照片也会按所在目录分组，但不会因此自动读取该目录的其余内容。要浏览目录中的所有照片，使用“打开文件夹”关联该目录。文件夹模式、已关联目录、展开位置和当前选择会在退出后保存。

“从列表移除”只隐藏该照片的引用，不改动原文件；刷新不会把隐藏照片重新加回来，主动重新导入则会恢复它。

## 数据存储

正常运行只持久化 `~/Library/Application Support/Luma/library.json`，其中包含照片及目录的文件位置、文件书签、浏览模式、展开位置与当前选择。缩略图缓存在内存中，不写入图库。

文件书签会尽量跟踪原文件移动；硬盘断开、权限变化或书签失效时，需要重新连接硬盘或重新定位文件。App 无法保证跟踪所有跨卷移动。

## 构建与验证

只需 Apple Command Line Tools 或 Xcode，Swift 5.9 及以上，无第三方依赖。

```bash
bash scripts/build-app.sh
bash scripts/test.sh
# 可选：加上实际 RAW 文件，验证完整 RAW 解码路径
LUMA_RAW_FIXTURE=/absolute/path/photo.NEF bash scripts/test.sh
```

`build-app.sh` 在项目的同级目录生成 `Luma.app`，会替换该目录已有的 Luma 构建。默认中间文件写入项目 `.build/`，可用 `LUMA_BUILD_DIR` 指定别处。

验证脚本独立运行，不依赖完整 Xcode 的 XCTest。覆盖多格式实际解码、EXIF 和旋转、图片尺寸限制、批量导入、去重、重启恢复、原片内容不变、移除不删除文件，以及缺失／损坏文件错误。

0.2 增加文件夹层级、展开／收起、目录内导航、磁盘内容刷新、空目录、目录移动和旧图库兼容检查。

开发时可用 `Luma.app/Contents/MacOS/Luma --library /absolute/path/test-library.json` 指定独立图库，不影响正常图库。

## 第一版边界

- RAW 兼容性依赖当前 macOS 支持的相机和编码变体；识别扩展名不等于每一款相机都可以解码。
- 当前用于审美浏览，不是 RAW 调色软件。主预览最长边限制为 4600 像素，缩略图最长边 240 像素；未提供全分辨率 1:1 检查、编辑、导出或打印。
- RAW 使用系统默认显影，观感可能与相机 JPEG 或其他调色软件不同。
- 当前不管理视频和 Live Photo 动态部分，也没有云同步。
- 本次提供的可执行包只编译了 Apple Silicon 架构；Intel Mac 可在对应机器上用源码构建。

## 技术依据

原生 SwiftUI + AppKit，Image I/O 提取元数据和生成预览，Core Image 解码 RAW。

- [Apple：CIRAWFilter](https://developer.apple.com/documentation/coreimage/cirawfilter)
- [Apple：文件书签](https://developer.apple.com/documentation/foundation/nsurl/bookmarkdata(options:includingresourcevaluesforkeys:relativeto:))

测试中使用的真实 Nikon RAW 来自 [rawpy 测试资料](https://github.com/letmaik/rawpy/tree/main/test)，仅作为开发测试输入，不随应用或源码打包。
